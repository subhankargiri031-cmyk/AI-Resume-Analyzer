 AI Resume Analyzer

A Python Flask web application that analyzes resumes, extracts skills, matches resumes with job requirements, calculates match scores, and stores analysis history.

Technologies Used
- Python
- Flask
- HTML, CSS, JavaScript

Features
- Resume Analysis
- Skill Extraction
- Job Match Score
- Analysis History

How to Run

pip install -r requirements.txt
python app.py
